# Workflows-Dokumentation

🇬🇧 [English](../en/README.md)

Workflows bringt redaktionelle Abläufe in Statamic 6: einen Zustandsautomaten für deine Einträge, Zuständige, Freigaben, Kommentare, Benachrichtigungen, Inhaltsalterung und Übersetzungsmanagement, alles direkt im Control Panel.

## Loslegen

1. [Installation](installation.md): Paket installieren und den Installer ausführen.
2. [Konfiguration](configuration.md): `config/workflows.php` an dein Projekt anpassen.
3. [Workflows definieren](workflows.md): Places und Transitions in YAML beschreiben, oder
4. [Workflow-Editor](editor.md): sie visuell im CP bauen.
